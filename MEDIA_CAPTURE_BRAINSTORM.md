# Media Capture Brainstorm

This is the shortlist of screenshots and screen recordings that would make the portfolio feel much more real once you have time to capture them.

## General rules

- Keep recordings short: `20-45 seconds`
- One story per recording
- Hide browser clutter, tabs, bookmarks, and desktop noise
- Use clean crops and consistent aspect ratios
- Prefer showing a workflow over showing a static screen
- If a project does not have a pretty UI, use diagrams, Swagger, logs, charts, or data views instead

## Buzzr Ecosystem

### Best screenshots

- mobile home feed
- game detail / rating screen
- social or watch-party screen
- desktop landing page hero
- desktop section that explains product positioning or features

### Best recording

- open the mobile app
- browse into a live game
- submit a rating
- show the social or party element
- end on the desktop web experience

### Why this works

- shows product taste
- shows this is more than a class project
- makes the “ecosystem” story obvious

## Medscribe

### Best screenshots

- note input screen before analysis
- structured summary output
- recommendation or suggested-orders area
- citations / provenance / evidence view

### Best recording

- paste or type the clinical note
- trigger analysis
- show structured result
- scroll through evidence / provenance

### Why this works

- proves the workflow is real
- makes the AI story feel grounded
- shows trust-building design, not just model output

## Ledger OKCU

### Best screenshots

- Swagger overview page
- one create-member or create-account request
- deposit or withdrawal response
- transaction history response
- simple entity relationship diagram

### Best recording

- create member
- create account
- deposit funds
- replay the same request to show idempotency
- show transaction history or audit trail

### Why this works

- backend work is hard to “see” without this
- makes the .NET story much more credible
- helps recruiters immediately understand what the API does

## Business Analytics Dashboard

### Best screenshots

- file upload screen
- validation or cleanup view
- anomaly-detection or error state
- final dashboard with forecast output

### Best recording

- upload a messy CSV
- show validation feedback
- move into cleaned analytics view
- end on forecast / anomaly output

### Why this works

- shows you understand real-world data problems
- makes the project look useful, not just academic
- helps for analytics-engineer and data-heavy roles

## Graph Link Prediction

### Best screenshots

- graph or dataset overview visual
- training or evaluation chart
- concise architecture diagram
- results summary panel or slide

### Best recording

- explain the dataset
- explain the model choice
- show training/evaluation output
- end with the takeaway: why graph learning mattered here

### Why this works

- technical projects need visual proof too
- diagrams are stronger than random notebook screenshots

## Priority order

If you only have time to capture a few things, do them in this order:

1. Medscribe demo recording
2. Ledger OKCU Swagger + transaction flow screenshots
3. Business Analytics Dashboard upload/validation/dashboard screenshots
4. Buzzr updated mobile + desktop capture set
5. Graph Link Prediction diagrams/charts
