# Media Capture Plan

This file exists to remove ambiguity. The portfolio is strongest when every flagship project has real visual proof.

## File destination

Put final screenshots and recordings here:
- `public/projects/`

Use names like:
- `buzzr-home.png`
- `medscribe-note-input.png`
- `medscribe-structured-output.png`
- `business-dashboard-upload.png`
- `business-dashboard-forecast.png`
- `ledger-okcu-swagger.png`
- `ledger-okcu-transaction-flow.png`
- `graph-link-prediction-architecture.png`
- `graph-link-prediction-auc.png`

## Graph Link Prediction

Use technical visuals instead of app UI screenshots.

Visuals:
- architecture diagram
- dataset scale / graph visual
- training or evaluation chart
- AUC or result summary graphic

Recording:
- short technical walkthrough
- explain the graph problem
- explain the model choice
- explain the evaluation result

## Quality bar

Do not use:
- blurry screenshots
- raw desktop clutter
- accidental browser tabs/bookmarks
- long shaky recordings
- placeholder visuals in final launch state

Use:
- consistent crops
- short intentional recordings
- one clear story per project
- visible proof of the strongest workflow
